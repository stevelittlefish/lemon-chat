Adventure overview

The magical forest of Eldoria is failing. Three ancient Heartstones — the source of the forest's protective barriers — have vanished from their sacred places. The Shadowfangs, corrupted creatures that have stalked Eldoria for two hundred years, grow bolder each night the stones remain missing.

The player wakes in Seraphina's Glade, having been found unconscious after a Shadowfang attack. Seraphina, the forest's gentle guardian, has healed their wounds — but she cannot leave her glade without the safety of everyone sheltered there collapsing. She asks the player to go in her place and recover the three stones before it is too late.

Objectives

The Grove and Mill can be tackled in any order. Shadow Peak is locked until at least one stone is found.

  1. Grove Heartstone — Ancient Grove, east. Challenge: the Corrupted Treant.
  2. River Heartstone — Sunken Mill, north-west. Challenge: pass the River Spirit Lyra's test of character.
  3. Peak Heartstone — Shadow Peak, north. Challenge: confront Malgrath the Shadowfang Alpha. Locked until one other stone is found.
  4. Restore the Seal — Return to Seraphina's Glade with all three. No dice needed — succeeds automatically.

Setup steps

  1. Go to Settings → Notes and create each of the six notes in the section below. Paste the content shown exactly.
  2. After saving each note, enable the Read-only toggle for every note marked read-only. This protects your lore from accidental modification.
  3. Go to Settings → Characters and create a new character called The Chronicler using the configuration below.
  4. Start a new conversation with The Chronicler. It will search for available adventures automatically.
Easier for younger players: Before starting, edit g.eldoria and change player_health = "3" to "5". Remember to turn read-only back on after editing.

Notes to create

Six notes in total. Enter the key exactly as shown. Mark read-only after saving.

g.eldoria
global read-only
Adventure manifest — the first note loaded. Contains the intro, load instructions, initial world state, and objectives.
g.eldoria.rules
global read-only
Game mechanics — dice rules, health, healing sources, and pacing rules the GM must follow.
g.eldoria.world
global read-only
World lore — locations, key NPCs, atmosphere, and hidden details for each area.
g.eldoria.bestiary
global read-only
Encounter cards — load when combat or a challenge begins. Defines exact dice outcomes for each encounter.
g.eldoria.secrets
global read-only GM only
GM-only lore — loaded immediately but never revealed to the player. Informs foreshadowing, NPC behaviour, and the emotional texture of the story.
g.eldoria.victory
global read-only
Victory narration — read aloud when all three stones are placed in the Great Seal.

Game master character

Create this in Settings → Characters.

The Chronicler new character
Name The Chronicler
Description A game master for the Eldoria text adventure. Reads lore notes, tracks world state, rolls dice fairly, and narrates a story with real stakes and a real chance of failure.
Tools to enable
world_state note_load note_list roll_dice random_chance

Use note_load and note_list individually rather than the notes group — this gives the GM read access without write access.

First message Leave blank — the GM's first action is to search for available adventures.

System prompt — paste into the System Prompt field

Starting play

  1. Start a new conversation with The Chronicler.
  2. The GM will search for adventures and present Eldoria. Say "Eldoria" or "I want to play Eldoria."
  3. The GM loads the lore, sets world state, and reads the opening narration. Play begins.
  4. Each response ends with three choices. Pick one and continue.
If the GM skips a dice roll or resolves an objective too easily: tell it directly — "You didn't roll dice for that. Check the rules note." The system prompt is designed to prevent this, but a reminder always works.

Adjusting difficulty

Turn off read-only, edit the note, then turn read-only back on.

  • Easier: In g.eldoria, change player_health = "3" to "5".
  • Easier: In g.eldoria.rules, change partial success threshold from 7 to 6 (so 6–9 = partial, 5– = failure).
  • Harder: Change starting health to "2".
  • Harder: In g.eldoria, add a note to the stone_peak objective that it requires both other stones before it unlocks.
