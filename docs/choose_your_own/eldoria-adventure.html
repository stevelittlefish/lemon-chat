Adventure overview

The magical forest of Eldoria is failing. Three ancient Heartstones — the source of the forest's protective barriers — have vanished. The Shadowfangs grow bolder each night the stones remain missing.

The player wakes in Seraphina's Glade, healed after a Shadowfang attack. Seraphina cannot leave without endangering everyone sheltered there. She asks the player to go in her place.

Objectives

Grove and Mill can be tackled in any order. Shadow Peak is locked until at least one stone is found.

  1. Grove Heartstone — Ancient Grove, east. Challenge: the Corrupted Treant.
  2. River Heartstone — Sunken Mill, north-west. Challenge: pass River Spirit Lyra's test.
  3. Peak Heartstone — Shadow Peak, north. Challenge: confront Malgrath the Shadowfang Alpha. Locked until one other stone is found.
  4. Restore the Seal — Return with all three stones. No random check needed.

Why pick_random instead of dice

With dice, the LLM sees a number and decides what it means afterwards — which invites cheating. With pick_random, the outcome string is encoded directly in the options list, so the result is the outcome. No interpretation step, no wiggle room.

The pattern is: write the outcomes in text first → encode them in the options list → call the tool → apply exactly what was returned.

Setup steps

  1. Go to Settings → Notes and create each of the six notes below, pasting the content exactly.
  2. After saving each note, enable Read-only for every note marked read-only.
  3. Go to Settings → Characters, create a new character called Choose Your Own, and paste in the system prompt.
  4. Start a new conversation with Choose Your Own. It will find and offer the Eldoria adventure automatically.
Easier for younger players: Before starting, edit g.cyo.eldoria and change player_health = "3" to "5". Turn read-only back on after editing.

Notes to create

Six notes total. Enter the key exactly as shown and mark read-only after saving.

g.cyo.eldoria
globalread-only
Adventure manifest — loaded first. Contains load instructions, initial world state, objectives, and the opening narration.
g.cyo.eldoria.rules
globalread-only
Game mechanics — randomness system, health, healing, response length, emoji, and image guidance.
g.cyo.eldoria.world
globalread-only
World lore — locations, key NPCs, and hidden details for each area.
g.cyo.eldoria.bestiary
globalread-only
Encounter cards — load when combat begins. Defines the exact pick_random list and outcomes for each challenge.
g.cyo.eldoria.secrets
globalread-onlyGM only
GM-only lore — never revealed directly. Informs foreshadowing, NPC behaviour, and emotional texture.
g.cyo.eldoria.victory
globalread-only
Victory narration — read aloud when all three stones are placed in the Great Seal.

Game master character

Create in Settings → Characters.

Choose Your Own new character
Name Choose Your Own
Description A game master for lemon-chat text adventures. Reads lore notes, tracks world state, resolves challenges fairly, generates images, and narrates with real stakes.
Tools
world_state note_load note_list note_to_self pick_random random_chance generate_image_sdxl

Use note_load, note_list, and note_to_self individually (not the notes group). note_to_self records outcomes privately before each random call — they stay in model context only, not shown in chat. Do not include roll_dice — the numeric result allows post-hoc interpretation.

First message Hello adventurer. What is your name?

System prompt

Starting play

  1. Start a new conversation with Choose Your Own.
  2. It will present available adventures. Say "Eldoria".
  3. The GM loads lore, sets world state, generates an opening image, and reads the intro. Play begins.
  4. Each response ends with three choices. Pick one each turn.
If the GM skips a random check or declares outcomes after seeing the result: say "You need to state the outcomes before calling pick_random — check the rules note."

Adjusting difficulty

Turn off read-only, edit, then re-enable read-only.

  • Easier: In g.cyo.eldoria, change player_health = "3" to "5".
  • Easier: In g.cyo.eldoria.bestiary, shift the Treant list to EASY and Malgrath to MEDIUM.
  • Harder: Change starting health to "2".
  • Harder: Require both Grove and Mill stones before Shadow Peak unlocks.
