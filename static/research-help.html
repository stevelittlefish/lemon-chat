Research in lemon chat

From a good question to a useful report

Research runs a deliberate loop of planning, searching, reading, synthesis, and review. This guide explains how to shape the work and what to expect while it runs.

Good starting point

State the decision you need to make, the evidence that matters, and any limits on geography, date, budget, or audience.

01 · The brief

Write a question with edges

The title labels the saved job. The prompt is the working brief sent to the researcher. You can provide either one, but a descriptive title plus a specific prompt usually produces the clearest result.

Too broad

Tell me about local AI.

More useful

Compare privacy, hardware cost, and maintenance trade-offs for running a local family chat assistant in the UK in 2026. Prefer first-hand evidence and identify unresolved risks.

Ask for comparisons, counter-evidence, implementation constraints, or a recommendation when those are important. Mention what you already know so the researcher does not spend rounds rediscovering it.

02 · Mode

Research or brainstorm

Research

Best for factual questions, comparisons, fact checks, product research, and how-to reports. Every round searches the web and grounds the evolving report in extracted sources.

Brainstorm

Best for invention, design, strategy, naming, planning, and exploring options. The model develops ideas first and searches only when evidence would improve them.

Always search the web appears in brainstorm mode. Enable it when the first creative round must include external evidence rather than relying entirely on the model's knowledge.

03 · Controls

Choose depth without wasting time

Model
The model plans, extracts evidence, synthesizes findings, and writes the report. The default uses the research model configured by the server.
In-depth report
Builds an outline, critiques it, writes sections from raw findings, and joins them into a longer report. It takes more time but retains more source detail.
Effort
Controls the number of normal and bonus rounds. Start with default. Use extra or too much for broad questions where fresh search angles are worth the added model time.
Time limit
Caps active research time. Waiting for a Reddit import does not consume this budget. A run can finish earlier when the model decides the report is sufficient.

04 · Reddit import

Bring first-hand discussions in through your browser

Reddit often blocks reliable server-side reading. Pause to import Reddit results lets lemon chat stop after search and ask the Save Reddit extension to capture selected threads using your normal browser session.

  1. 1
    Enable the option

    Start the job with the Reddit import checkbox selected.

  2. 2
    Copy the request

    When the job pauses, copy or download its versioned request bundle.

  3. 3
    Capture in the extension

    Paste the request into Save Reddit. It visits threads sequentially and reports limits, warnings, and failures honestly.

  4. 4
    Import the response

    Paste or upload the exported JSON. Lemon chat validates it, extracts relevant evidence, and resumes the exact saved round.

You may skip the Reddit sources and continue with ordinary webpages. Reloading or restarting while paused is safe: the request is stored with the research job, and waiting time is excluded from the active time limit.

05 · Progress

What happens while it runs

PlanSearchReadSynthesizeDecideWrite

The live panel shows the current phase, round, queries, pages being read, and a tail of generated text. Closing the page does not stop the job. Pending and running jobs resume from their latest checkpoint after a server restart.

Cancel stops an active job or closes an awaiting Reddit handoff. A cancelled or failed job may retain its partial evolving report for diagnosis.

06 · Results

Read the report as an evidence map

Reports include source references and a record of analyzed URLs. Follow citations when a claim matters, review uncertainty and capture warnings, and distinguish first-hand discussion from stronger primary evidence.

Completed reports can be downloaded as Markdown for editing or as a self-contained HTML document for reading and sharing.

07 · Troubleshooting

Common problems

No usable search results

Confirm SearXNG is configured and reachable. Make the prompt less narrow, remove conflicting constraints, or try a different wording.

The run stops with few findings

Some pages may block fetching or contain too little useful text. Increase effort, broaden the brief, or explicitly request alternative source types.

A Reddit response is rejected

Reload the unpacked extension, recapture using the current request, and keep the request and response IDs together. Do not edit URLs or combine responses from different jobs.

The extension reports partial capture

Review its warnings. Comment limits, collapsed branches, access gates, deleted content, rate limits, and Reddit markup changes can prevent a complete capture. Partial results can still be useful when their limitations are understood.

A report needs more detail

Enable in-depth reporting, raise effort or time, and state the missing dimensions in the brief. A focused follow-up job is often better than an unbounded first request.
